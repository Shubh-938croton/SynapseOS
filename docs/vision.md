# SynapseOS

## Vision

SynapseOS is a cognitive productivity operating system designed to help students learn effectively, stay focused, track progress, manage knowledge, and eliminate distractions.

## Mission

To centralize every productivity tool into one intelligent dashboard.

## Target Users

- Students
- Competitive Programmers
- Developers
- Lifelong Learners

## Future Vision

An AI-powered productivity platform that helps people learn better.

## Current Product Direction

The current implementation has established SynapseOS as a full-stack student productivity platform with:

- React frontend
- Node.js/Express REST backend
- MySQL relational database
- JWT authentication
- bcrypt password hashing
- Productivity CRUD modules
- Analytics
- Notifications
- User profile management

The next differentiating feature is **YouTube Productivity**: using YouTube as a learning resource while adding SynapseOS-specific organization, tracking, notes, completion, and productivity analytics.

Avatar support and dark theme are intentionally deferred to the final polishing phase.
